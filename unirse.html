Join the directory

No necesitas saber Git ni GitHub. El formulario de abajo es una página normal de internet — solo necesitas una cuenta gratuita de GitHub para enviarlo.

You don't need to know Git or GitHub. The form below is a normal web page — you just need a free GitHub account to submit it.

  1. Crea una cuenta gratuita en github.com si aún no tienes una (toma dos minutos). Create a free account at github.com if you don't have one yet (takes two minutes).
  2. Haz clic en «Abrir formulario» abajo y completa tu nombre, institución, región (Costa/Sierra/Amazonía), taxones o temas de interés, y enlaces (perfil, Google Scholar, ORCID). Click "Open form" below and fill in your name, institution, region (Costa/Sierra/Amazonía), taxa or research interests, and links (profile, Google Scholar, ORCID).
  3. Envía el formulario. Esto crea un issue (una solicitud) que el equipo de SPBE revisa antes de publicarlo — así el directorio se mantiene confiable. Submit the form. This creates an issue (a request) that the SPBE team reviews before publishing — this keeps the directory reliable.
  4. Una vez aprobado, tu perfil aparece en el directorio. Te avisaremos en el mismo issue. Once approved, your profile appears in the directory. We'll notify you on the same issue.
